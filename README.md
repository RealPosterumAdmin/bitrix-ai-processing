# bitrix-ai-processing

Репозиторий содержит стартовый production-ready каркас Bitrix-модуля `realposterum.ai.processing` для AI-обработки карточек товаров с обязательным подтверждением администратора.

## Что добавлено

- модуль в `/local/modules/realposterum.ai.processing`
- установка/удаление модуля и SQL-схема очереди задач
- ORM-таблица и репозиторий для хранения AI-задач
- сервисы построения snapshot товара, prompt и вызова AI API
- административные страницы для постановки в очередь, запуска AI и применения/отклонения результата
- страница настроек для API URL, токена, модели и шаблонов промптов

## Сценарий работы

1. Администратор указывает `IBLOCK_ID` и `PRODUCT_ID` на странице очереди.
2. Модуль сохраняет snapshot товара и готовый prompt в таблицу `b_realposterum_ai_task`.
3. По кнопке «Обработать» выполняется запрос к AI API и сохраняется JSON-ответ.
4. По кнопке «Применить» изменяются поля и свойства товара.
5. По кнопке «Отклонить» задача закрывается без изменения карточки.

## Настройки

В настройках модуля доступны:

- `AI API URL`
- `AI API token`
- `Модель`
- `Системный промпт`
- `Шаблон пользовательского промпта`

## Ограничения стартовой версии

- рассчитано на установку в Bitrix с модулями `main` и `iblock`
- HTTP-клиент использует стандартный `Bitrix\Main\Web\HttpClient`
- формат AI-ответа ожидается в JSON с ключами `fields`, `properties`, `summary`
